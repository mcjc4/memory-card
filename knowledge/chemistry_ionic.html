类型离子减少的途径典型例子
复分解生成水 / 沉淀 / 气体 / 弱电解质H⁺+OH⁻=H₂O；Ag⁺+Cl⁻=AgCl↓
氧化还原电子转移使离子价态改变HClO(弱)+H₂SO₃(弱)→H₂SO₄+HCl（虽都弱酸不拆，但氧还成立）
络合生成稳定配合物，自由离子减少Fe³⁺ + SCN⁻ → [Fe(SCN)]²⁺ 血红色
双水解水解互相促进，彻底生成沉淀+气体Al³⁺ + 3HCO₃⁻ → Al(OH)₃↓ + 3CO₂↑（泡沫灭火器）
⚠️ 固体 CO₂（干冰）与水、CaCO₃ 与 CO₂ 水溶液等无自由离子参与的，不算离子反应。

强弱酸制取规律与特例

一般规律

强酸制弱酸。弱酸不能制强酸——如 SO₂ 与 BaCl₂ 不反应（假设生成的 BaSO₃ 会被 HCl 拉回）。

特例① 弱制强（沉淀驱动）

H₂S(弱)+CuSO₄→CuS↓+H₂SO₄；AgNO₃+HCl→AgCl↓。沉淀无法逆向，反应成立。

特例② 难挥发制易挥发

浓 H₂SO₄(高沸)+NaCl(固)→Na₂SO₄+HCl↑（加热）。

记忆锚点

规律看"产物更弱 / 更难溶 / 更易逸出"；三特例本质是沉淀或气体把平衡拽过去。

题型二 · 书写离子方程式
该拆拆，不该拆不拆；量决定产物
类别拆成离子保留化学式
该拆强酸、强碱、可溶性盐—
不拆—弱酸/弱碱/水(弱电解质)、沉淀、气体、氧化物、浓硫酸、石灰乳(悬浊)
🧠️ 同一物质状态不同拆法不同：澄清石灰水（Ca(OH)₂ 溶）要拆；石灰乳（悬浊）不拆；生成的漂白粉是固体也不拆。

量决定产物：CO₂ 三连

酸性顺序：碳酸 > 苯酚 > 碳酸氢根　→　苯酚钠 + CO₂ 恒得 HCO₃⁻（得不到 CO₃²⁻）

体系产物原因
CO₂ + 碱（碱过量）CO₃²⁻正盐

苯酚钠 + CO₂（无论过量）HCO₃⁻苯酚酸性弱于 HCO₃⁻，无法生成 CO₃²⁻

Ca(ClO)₂ + CO₂CaCO₃↓Ca²⁺ 与 CO₃²⁻ 结合成难溶物，拽向沉淀

三大书写特例

双水解

Al³⁺+3HCO₃⁻→Al(OH)₃↓+3CO₂↑；沉淀+气体互促，彻底。

电解食盐水

2Cl⁻+2H₂O→(电解)2OH⁻+H₂↑+Cl₂↑；Cl⁻与H₂O反应是离子反应。

配平用 NH₄⁺

含氨水/铵盐时，电荷守恒直接写 NH₄⁺，别写 H⁺（H⁺会先与 NH₃·H₂O 结合）。
✎️ 配平铁律：原子守恒 + 电荷守恒双满足；变价元素注意归中/歧化（如碳酸钡与酸→CO₂+H₂O+Ba²⁺）。
互动 ｜ 拆与不拆：一个动作决定方程式对错

题型三 · 实验检验与离子共存
操作严谨，结论才可靠
离子操作现象易错点
Na⁺/K⁺铂丝/铁丝蘸取，火焰灼烧Na 黄；K 紫（透蓝钴玻璃）K 必须透蓝钴玻璃滤黄光；玻璃棒含 Na 会干扰；黄色只证含 Na 不一定是钠盐
Fe³⁺加 KSCN / 铁氰化钾血红色 / 蓝色沉淀—
NH₄⁺浓 NaOH + 加热，湿红石蕊气体使试纸变蓝必须浓碱+加热，稀碱/常温 NH₃ 难逸出
Cl⁻/Br⁻/I⁻先 HNO₃ 酸化，再加 AgNO₃AgCl 白 / AgBr 淡黄 / AgI 黄酸化与沉淀试剂分开加，排除 Ag⁺ 等干扰
SO₄²⁻先 HCl 酸化，再加 BaCl₂白色 BaSO₄↓先酸化排除 Ag⁺、SO₃²⁻、CO₃²⁻ 干扰
SO₃²⁻加 HCl 产气，通品红品红褪色正盐/酸式盐现象相同难区分；含 S₂O₃²⁻ 先过量 HCl 分解过滤再验 SO₄²⁻
🔬️ I⁻ 严谨方案：先加淀粉不变色（排除原碘单质）→ 再加氧化剂变蓝，才是 I⁻ 被氧化。

化工流程 · 成分去向与 H₂O₂ 双重性

成分去向

酸浸：金属氧化物/活泼金属入液；不活泼金属(如 Cu)、难溶盐(如 PbSO₄)留渣。盯紧隐含氧化还原。

H₂O₂ 双重性

既可作氧化剂(氧化 Pb²⁺→Pb⁴⁺)也可作还原剂(还原 Pb⁴⁺→Pb²⁺)，看化合价变化定角色。
🧠️ 配平五步：标变价 → 算升降 → 定系数 → 补电荷(酸补 H⁺) → 补原子(补水)。空气/O₂ 常把 Fe²⁺→Fe³⁺、Mn²⁺→高价，别漏写氧化步。

易错点 Top 10（信号 → 结论）
混元 3-hy3 重排，按高频踩坑排序
1

信号：看到"弱酸制强酸" → 先想有没有沉淀/气体拽着平衡走（H₂S+CuSO₄、AgNO₃+HCl 才成立）。

2

信号：石灰乳 / 澄清石灰水 → 悬浊不拆、澄清拆，漂白粉固体也不拆。

3

信号：K⁺ 焰色 → 必须透过蓝色钴玻璃；玻璃棒含钠会干扰，不能用玻璃棒蘸。

4

信号：检验 NH₄⁺ → 必须浓 NaOH + 加热，稀碱或常温氨气难逸出。

5

信号：检验 SO₄²⁻ → 先盐酸酸化再加 BaCl₂，排除 Ag⁺/SO₃²⁻/CO₃²⁻ 干扰。

6

信号："澄清透明" → 不等于无色，Cu²⁺(蓝)/Fe³⁺(黄) 照样可共存。

7

信号：水电离[H⁺]极低 → 溶液可能强酸也可能强碱，双向都要验。

8

信号：CO₂ 通入苯酚钠 → 无论是否过量都只得 HCO₃⁻（碳酸>苯酚>碳酸氢根）。

9

信号：含铵根/氨水配平 → 电荷守恒直接写 NH₄⁺，别写 H⁺。

10

信号：铝热反应表述 → 反应物是 Al 与 Fe₂O₃，"氧化铁和氧化铝发生反应"是错的。
