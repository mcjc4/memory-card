🧭 八字方针怎么用整体处理：将 $\omega x+\varphi$ 视为整体 $t$，根据 $t$ 的范围求出目标量的范围；原图对照：画出基础函数（如 $\sin t$）的图像，在 $t$ 的范围内直观寻找单调区间。避免直接解不等式，图像判断更快更准。
1

奇偶性判断：奇变偶不变

🔄 判断流程

  • 利用诱导公式「奇变偶不变」，核心看相位变换后是否改变函数名
  • $f(x)=\sin(\omega x+\varphi)$ 为偶函数 → 需转化为 $\pm\cos\omega x$ 形式 → $\varphi=\dfrac{\pi}{2}+k\pi$（不换名）
  • 为奇函数 → 需转化为 $\pm\sin\omega x$ 形式 → $\varphi=k\pi$（换名）
  • 判断时只关注是否「换名字」，符号变化不影响奇偶性本质
2

单调区间 · 对称性 · 复合函数

📈 单调区间求法

  • 整体处理 + 原图对照（见上方八字方针）
  • 例：求 $y=\sin\left(2x-\dfrac{\pi}{3}\right)$ 增区间 → 令 $t=2x-\dfrac{\pi}{3}\in\left[-\dfrac{\pi}{2}+2k\pi,\dfrac{\pi}{2}+2k\pi\right]$ 再解出 $x$

🎯 对称轴与对称中心

  • 判断对称轴：代入点后函数值为 $\pm1$ → 是对称轴
  • 判断对称中心：代入点后函数值为 $0$ → 是对称中心
  • 注意平移影响：如 $y=\sin\left(2x+\dfrac{\pi}{3}\right)+1$，对称中心纵坐标是 1 而非 0
  • 相邻两对称轴间距 = 半个周期 $\dfrac{T}{2}$

🧩 复合函数单调性：同增异减

  • 内外层单调性相同 → 增；不同 → 减
  • 外层系数为负（如 $y=-\sin\omega x$）求增区间 → 找内层的减区间
  • 解题第一步建议先提取负号，统一形式后再套原则，避免符号错误
3

易错点与书写规范

📐 定义域与区间端点

  • $\tan x$ 在 $x=\dfrac{\pi}{2}+k\pi$ 处无定义，单调区间必须用小括号（开区间）
  • 题目给定闭区间但端点不在定义域内 → 必须修正为开区间

✂️ 多区间连接规范

  • 多个单调区间用「逗号」或「和」连接
  • 严禁用「∪」或「或」：并集表示整个集合上单调，而分段单调函数在断点处不满足整体单调（如反比例函数）
  • 填空题若要求集合形式注意格式；问区间直接写区间

🔁 三角恒等变换技巧

  • 已知角求值优先选 cos：$\cos$ 在 $[0,\pi]$ 单调递减，一一对应，无需讨论符号
  • 利用角的拆分（如 $\alpha=(\alpha+\beta)-\beta$）进行「知一求二」
  • 注意三角形内角范围对 $\sin$、$\cos$ 符号的限制
