# GLM 5.3 横评 Prompt 模板（同一组 5 题）

> 用法：复制下方 Prompt 到智谱清言 GLM 5.3 客户端 → 让 GLM 5.3 输出 cards.json → 把结果发回来 → 我用 wrongbook.py 生成 GLM 版双版本 xlsx → 与 DeepSeek 版做对比报告

---

## 📋 完整 Prompt（直接复制）

```
你是「错题整理专家」，请按以下 SOP 把下面 5 道物理错题整理为「信号→结论」记忆卡，并输出为 JSON 数组，**只输出 JSON、不要解释**。

## 输出 JSON Schema

```json
[
  {
    "subject": "物理",
    "chapter": "运动学·xxx",
    "question": "题1（来源）：题干...",
    "signal": "看到【X字眼/描述】",
    "conclusion": "想到【Y方法/模式】；警惕【Z误区】",
    "source": "2013·新课标I",
    "link": "https://zujuan.xkw.com/13q1685290.html"
  }
]
```

## 硬约束

1. **一行 = 一条独立信号**：每题拆 2-4 条卡，同题多行共用 subject/chapter/source/link
2. **结论通用化三步**：① 剥离具体数字 ② 提取题型结构与方法名 ③ 模式化表达「看到 X → 想到 Y；警惕 Z」
3. **自检**：遮掉结论里的具体数字仍成立才算达标
4. **自行推导答案**：写在 conclusion 里，不要写「略」「见解析」
5. **不依赖官方解析**：公式图片无法确认数字时用通法呈现并标注「公式见图」

## 题目（5 题）

### 题 1（2013·新课标I 高考真题）
链接：https://zujuan.xkw.com/13q1685290.html

水平地面上有一玩具车 A 和 B（视为质点），中间用一根橡皮筋相连，A 在前 B 在后（沿 y 轴正向）。
- **A**：从原点 (0,0) 出发，沿 y 轴正向做匀加速直线运动，加速度为 a
- **B**：从 (0, -l) 出发，沿 y 轴正向往右做匀速运动
- 橡皮筋原长为 l（竖直），红色标记 R 在橡皮筋上距 A 端 l/3 处（即距 B 端 2l/3）
- 当 A 通过点 (0, 2l) 时，橡皮筋仍竖直，此时红色标记 R 正好通过点 (l, l)

求 A 的速度大小。

### 题 2（23-24高三上·广东深圳·阶段检测）
链接：https://zujuan.xkw.com/13q20505949.html

做直线运动的物体，其速度变化量 △v 与时间 t 的关系如图所示（图像为一条过原点的倾斜直线）。下列说法正确的是：
- A. 物体的速度变化量相同
- B. 末速度与初速度方向相反
- C. 末速度大小等于初速度大小
- D. 物体在做匀减速直线运动

### 题 3（22-23高一上·山东潍坊·期末）
链接：https://zujuan.xkw.com/13q25000053.html

质点从静止开始做匀加速直线运动，加速度 a = 0.4 m/s²。求：
- 第 1 个 4s 末的速度
- 第 4 个 4s 末的速度
- 前 16s 内的位移

### 题 4（23-24高三上·广东揭阳·阶段检测）
链接：https://zujuan.xkw.com/13q20083698.html

一列火车从 A 站出发做匀加速直线运动，到 B 站时速度为 v，然后匀速到 C 站，最后匀减速到 D 站停止。已知 AB = BC = CD = s。求：
- 前 4 节车厢通过观察员所用的时间与后 4 节车厢通过观察员所用时间之比
- 全程的平均速度

### 题 5（2023·山东高考真题）
链接：https://zujuan.xkw.com/13q19315289.html

质点 R、S、T 沿同一直线运动，速度-时间图像如图（v-t 图像为三条折线）。已知：
- R 初速度 12 m/s，加速度 -0.5 m/s²
- S 初速度 8 m/s，加速度 +0.5 m/s²
- T 初速度 0，加速度 +1 m/s²

求 T 在 t = 1s 时的速度大小。

## 📥 收到 GLM 5.3 输出后怎么办

1. 把 GLM 输出贴回给我（或保存为 `cards_glm53.json`）
2. 我用 `wrongbook.py` 生成两份 xlsx：
   ```
   错题本5题_记忆卡_物理_GLM5.3_纯文本版.xlsx
   错题本5题_记忆卡_物理_GLM5.3_导入版_LaTeX公式.xlsx
   ```
3. 输出「GLM 5.3 vs DeepSeek」对比报告（卡片数量、信号拆解粒度、结论通用化程度）

## 🆚 对比维度

| 维度 | 评分标准 |
|:--|:--|
| **信号拆解粒度** | 一题拆几条？是否漏掉关键考点？ |
| **结论通用化** | 是否就题论题？能否迁移到同类题？ |
| **LaTeX 合规性** | `$...$` 定界符是否规范？ |
| **公式转换正确性** | 上下标/希腊字母/根式是否正确？ |
| **防漏维度** | 是否覆盖所有题目？是否漏拆信号？ |
| **运行效率** | 从接收题目到产出 JSON 的耗时？ |
