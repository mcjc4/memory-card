# 错题整理专家 SOP（外发版）

> 给其他 AI Agent 复刻使用。配套脚本 `wrongbook.py` + 本 SOP = 「信号→结论」记忆卡的完整生产链。
> 核心硬约束：**每次必须同时生成两份 xlsx，缺一不可**。

## 一、目标

把零散错题（错题本 / 组卷网 / 课堂纪要 / 截图）整理为「信号→结论」格式记忆卡，自动产出**双版本 xlsx**：

| 文件 | 用途 | 公式形式 |
|:--|:--|:--|
| `<name>_纯文本版.xlsx` | 不依赖 KaTeX 渲染的应用（如直接打印） | Unicode 上下标（`v²`、`√2`、`α`） |
| `<name>_导入版_LaTeX公式.xlsx` | 记忆卡应用导入（KaTeX 渲染） | `$...$` 定界（`$v^2$`、`$\sqrt{2}$`） |

文件名必须含**模型名**（`DeepSeek` / `Kimi-K3` / `GPT-4` 等），便于跨模型横评归档。

## 二、Phase 1 — 题目获取

### 输入形式
- 错题本 Excel / 文本 / 截图
- 组卷网链接形如 `https://zujuan.xkw.com/<ID>q<数字>.html`

### 操作
1. 从 Excel/文本提取「题目 + 详情链接」清单
2. 截图：用 Read 工具读图，OCR 出题干与选项
3. 组卷网：因 WAF 风控 + 需登录，详细题干优先靠截图，**链接仅作出处记录**

### 输出
```
题目清单（5 道题）：
1. 题干：...... ｜ 链接：https://zujuan.xkw.com/...
2. ......
```

## 三、Phase 2 — 答案推导

### 原则
- **自行分析计算**，不抓官方答案/解析
- 能算的题必须算出具体结果（如 `v=1/4√(6al)`、`n=14`）
- 公式为图片无法确认数字时：用**题型通法**呈现并标注「公式见图」，**禁止编造数字**

### 输出
每道题附带：
```
题1 答案：v = (1/4)√(6al)
推导：...（简要说明）
```

## 四、Phase 3 — 记忆卡提炼（信号→结论）

### 7 列结构（固定）

| 列 | 字段 | 填写规则 |
|:--:|:--|:--|
| A | 科目 | 物理/化学/英语/政治/数学/语文 |
| B | 章节知识点 | 如「运动学·连接体」 |
| C | 原题题干 | 「题N（来源）：…」 |
| D | 题干信号 | 「看到【X字眼/描述】」 |
| E | 结论/易错点 | 「想到【Y方法/模式】；警惕【Z误区】」 |
| F | 出处 | 试卷/教材/年份 |
| G | 题目链接 | 详情页 URL（如有） |

### 一行 = 一条独立信号

每道题拆 2-4 条卡片，**同题多行共用 A/B/F/G 四列**（即学科、章节、出处、链接相同），只在 C/D/E 列写各自的内容。

### 题干信号是原子信号

❌ 反面示例：「看到【连接体且伸长均匀，速度与位置关系】」
✅ 正面示例：「看到【连接体上的标记点，且题设"伸长均匀"】」

**怎么算原子**？拆到「看到这一行，就能联想起某个具体方法」的程度。

### 结论必须通用化（关键！）

三步通用化：

1. **剥离具体数字与对象**：把题目里的 `a=2m/s²`、`l=3m` 等具体数字去掉
2. **提取题型结构与方法名**：
   - 分离参数 / 同构 / 错位相减 / 凑角 / 设 $x=my-c$
   - 正弦定理 / 韦达定理 / 均值不等式 / 等等
3. **模式化表达**：「看到 X → 想到 Y；警惕 Z」

### 通用化自检

把结论里的具体数字遮掉仍成立 → ✅ 达标

残留本题数字 → ❌「就题论题」，必须重写

### 完整示例

**原题**：
题2（23-24高三上·深圳·阶段检测）：一质点做匀减速直线运动直至停止，依次通过三段相等位移，求三段的时间比。

**反例（就题论题）**：
- 信号：看到【通过三段相等位移】
- 结论：想到【时间比为 1:(√2-1):(√3-√2)】；警惕【算错比值】

**正例（通用化）**：
- 信号：看到【末速度为 0 的匀减速直线运动】
- 结论：想到【用逆向思维把过程倒过来作为"初速为 0 匀加速"，连续相等位移的时间比为 $1:(\sqrt{2}-1):(\sqrt{3}-\sqrt{2}):\dots:(\sqrt{n}-\sqrt{n-1})$】；警惕【正向代入常规公式导致复杂度翻倍】

## 五、Phase 4 — 调用脚本生成双版本 xlsx（绝对不能跳过！）

### 步骤

1. **把 Phase 3 提炼出的卡片写到 cards.json**（7 列字段对应 7 个 JSON 键）

2. **调用 `wrongbook.py`**：
   ```bash
   python wrongbook.py build cards.json ./output DeepSeek
   ```
   或在 Python 中：
   ```python
   from wrongbook import build_both
   from pathlib import Path

   cards = [...]  # list of dicts with 7 fields
   result = build_both(
       cards,
       Path('./output/错题本5题_记忆卡_物理_DeepSeek'),
       model_name='DeepSeek',
   )
   print(result['plain'], result['latex'])
   ```

3. **强制保证**（脚本内置 3 道断言，不可绕过）：
   ```python
   assert plain_path.exists()     # 纯文本版必须存在
   assert latex_path.exists()     # LaTeX 版必须存在
   assert plain_path.stat().st_size > 1000  # 纯文本版必须 > 1KB
   assert latex_path.stat().st_size > 1000  # LaTeX 版必须 > 1KB
   ```

### 输出规范

最终目录结构：
```
output/
├── 错题本5题_记忆卡_物理_DeepSeek_纯文本版.xlsx
└── 错题本5题_记忆卡_物理_DeepSeek_导入版_LaTeX公式.xlsx
```

## 六、Phase 5 — 校验交付

### 校验清单
- ✅ 行数 = 信号卡条数（不含表头）
- ✅ 抽查 2-3 行，确认「看到 X → 想到 Y；警惕 Z」格式
- ✅ 链接列完整、同题多行共用链接
- ✅ 两个文件都已生成、都能用 openpyxl 打开
- ✅ 文件名含模型名

### 交付清单
- ✅ 双版本 xlsx（必选）
- ✅ 核对报告：每题题干 / 选项数 / 答案 / 小问结构

## 七、核心硬约束（违反任一条视为任务失败）

| 编号 | 约束 | 失败后果 |
|:--:|:--|:--|
| 1 | **每次必须同时生成两个文件** | 用户拿不到完整产出 |
| 2 | **物理上不可能只出一个** | 脚本 `build_both()` 内置 3 道断言 |
| 3 | **命名必须含模型名** | 横评归档混乱 |
| 4 | **不依赖官方答案解析** | 失去自推导价值；除非用户明确要求 |
| 5 | **结论必须通用化** | 无法迁移到同类题 |
| 6 | **答案自推导** | 信号卡没有可迁移价值 |
| 7 | **过滤非教学内容** | 课堂纪要/截图中的闲聊、待办混入 |

## 八、常用公式 LaTeX 速查

| LaTeX | Unicode 纯文本 | LaTeX 版 |
|:--|:--|:--|
| `v^2` | `v²` | `$v^2$` |
| `\sqrt{2}` | `√2` | `$\sqrt{2}$` |
| `\dfrac{a}{b}` | `(a/b)` | `$\dfrac{a}{b}$` |
| `\alpha` | `α` | `$\alpha$` |
| `\Delta x` | `Δx` | `$\Delta x$` |
| `\geq` | `≥` | `$\geq$` |
| `\rightarrow` | `→` | `$\rightarrow$` |
| `\perp` | `⊥` | `$\perp$` |
| `\ln` | `ln` | `$\ln$` |
| `\omega` | `ω` | `$\omega$` |
| `\mathbb{R}` | `ℝ` | `$\mathbb{R}$` |

脚本自动转换，无需手动写 Unicode。

## 十、复刻清单

其他 AI agent 复刻本 SOP 时，只需：
1. 复制本文件 + `wrongbook.py`
2. 安装 `openpyxl`：`pip install openpyxl`
3. 把 SOP 当作 system prompt 或 skill 描述喂给 LLM
4. 调用 `wrongbook.py build cards.json ./output <model>` 即可产出双版本 xlsx
